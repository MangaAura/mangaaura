# Plan de Contenido para Redes Sociales — MangaAura

## Canales priorizados

1. **X/Twitter** — comunidad manga + noticias + hilos virales
2. **Instagram** — arte visual, carruseles educativos, Reels
3. **TikTok** — clips virales, trends, detrás de escena (cuando tengas tiempo)

---

## Pilares de contenido (4 temas)

| Pilar             | %   | Ejemplos                                                                |
| ----------------- | --- | ----------------------------------------------------------------------- |
| **Educativo**     | 40% | Guías, diferencias de géneros, cómo crear manga, qué leer según tu mood |
| **Comunidad**     | 30% | Logros de usuarios, rankings, clanes, eventos, historias de creadores   |
| **Producto**      | 20% | Features nuevas, cómo funciona Aura, crowdfunding, gamificación         |
| **Cultura manga** | 10% | Datos curiosos, recomendaciones, efemérides, memes                      |

---

## Calendario semanal

### Lunes — Tips educativos

- X: Hilo con guía rápida (ej: "5 mangas para empezar si eres nuevo")
- IG: Carrusel "Shonen vs Seinen en 4 diapositivas"
- TT: "¿Sabías que...?" dato curioso manga

### Martes — Comunidad

- X: Destacar top lector de la semana / logro de alguien
- IG: Story con encuesta "¿Cuál es tu género favorito?"
- TT: Clip rápido de alguien subiendo de nivel

### Miércoles — Producto / Feature

- X: Explicar Aura, crowdfunding, gamificación
- IG: Demo visual de una feature
- TT: "Mira cómo funciona X en MangaAura"

### Jueves — Cultura manga

- X: Efeméride o recomendación
- IG: Poster/arte con frase del día
- TT: Trend relacionado con manga

### Viernes — Fin de semana

- X: "Qué leer este fin de semana" hilo
- IG: Reels de arte manga + música
- TT: Challenge/trend semanal

### Sábado — Repost / user generated

- X: Retweetear menciones de usuarios
- IG: Compartir historias de creadores

### Domingo — Off / programado

## Imágenes / Visuales

- **Formato para X:** 1200x675 (tarjeta) o screenshot directo
- **Formato para IG:** 1080x1080 (cuadrada) o 1080x1920 (historia)
- **Formato para TT:** 1080x1920 video vertical

Usa el endpoint `/api/og?type=blog&title=...` de MangaAura para generar imágenes automáticas.
