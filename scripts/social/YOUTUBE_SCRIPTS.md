## 📹 Optimización Técnica para YouTube

### Thumbnails

| Elemento      | Regla                                 |
| ------------- | ------------------------------------- |
| **Texto**     | Máximo 3-4 palabras, legible en móvil |
| **Contraste** | Colores brillantes sobre fondo oscuro |
| **Rostro**    | Incluir expresión facial (si aplica)  |
| **Branding**  | Logo de MangaAura en esquina          |
| **Formato**   | 1280x720px, < 2MB                     |

**Ejemplos de thumbnails:**

- "¿DÓNDE PUBLICAR?" + flecha apuntando a logos de plataformas
- "MANGA CON IA 🤖" + comparación antes/después
- "GANAR DINERO 💰" + ilustración de monedas

### Títulos efectivos

| Fórmula                                    | Ejemplo                                        |
| ------------------------------------------ | ---------------------------------------------- |
| [Cómo/Guía] + [beneficio] + [año]          | "Cómo publicar tu manga GRATIS en 2026"        |
| [Número] + [formas/consejos] + [resultado] | "5 formas de ganar dinero con tu manga"        |
| [X] vs [Y] vs [Z] + ¿cuál elegir?          | "MangaAura vs MangaPlus: ¿cuál es mejor?"      |
| Pregunta + promesa                         | "¿Se puede crear manga con IA? Te enseño cómo" |

### Descripciones SEO

Cada descripción debe incluir:

1. **Resumen del video** (2-3 líneas)
2. **Timestamps** con secciones
3. **Enlaces** a plataformas mencionadas
4. **Llamada a la acción** (comentar, suscribirse)
5. **Hashtags** (3-5 relevantes)
6. **Enlace a MangaAura** (en descripción, no en el video)

### Tags recomendados

```
manga, crear manga, publicar manga online, manga plataformas, manga ia,
inteligencia artificial manga, manga tutorial, webtoon, manhwa,
leer manga online, crowdfunding manga, monetizar manga, manga creador
```

## 📝 Transcripciones para SEO

Las transcripciones de los videos deben publicarse como **blog posts** en MangaAura. Esto cumple dos objetivos:

1. **SEO para Google** — el contenido escrito indexa mejor
2. **AI SEO** — las IAs pueden citar el texto de la transcripción

### Flujo de trabajo:

1. Grabar video
2. Subir a YouTube
3. Descargar transcripción (YouTube Studio > Subtítulos)
4. Pulir y publicar como blog post en `/blog/`
5. Incluir el video embed en el blog post
6. Enlazar desde el blog post a las páginas relevantes de MangaAura

## 🎬 Producción: Mínimo Viable

### Equipo recomendado para empezar:

- **Micrófono:** Blue Yeti o Samson Q2U (~$50-100)
- **Cámara:** Webcam 1080p o smartphone
- **Edición:** DaVinci Resolve (gratuito) o CapCut (gratuito)
- **Thumbnails:** Canva (gratuito)
- **Guion:** Escribir en Google Docs

### Estilo recomendado:

- **Formato:** Tutorial con capturas de pantalla + talking head
- **Intro:** 5-10 segundos con logo animado (puedes hacerlo en Canva)
- **Outro:** "Suscríbete para más guías de manga" + enlaces
- **Música:** Biblioteca de audio de YouTube (gratis, sin copyright)
